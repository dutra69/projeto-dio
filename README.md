#  Laboratório de Cibersegurança: Criptografia e Monitoramento de Ativos em Python

Este repositório contém os projetos práticos desenvolvidos durante o Bootcamp de Segurança Cibernética da **DIO (Digital Innovation One)**. O objetivo deste laboratório foi compreender os mecanismos internos de ameaças comuns, como técnicas de criptografia de arquivos e monitoramento de periféricos, focando no desenvolvimento de contramedidas e análise defensiva.

>  **Aviso de Uso Seguro:** Todos os scripts foram desenvolvidos e executados estritamente em ambiente controlado de testes (`teste_files`), utilizando bibliotecas oficiais do Python para fins didáticos e de pesquisa em segurança.
